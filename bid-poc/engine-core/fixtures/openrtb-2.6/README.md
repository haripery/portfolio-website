# OpenRTB 2.6 example bid requests

`example-1.json` … `example-5.json` are the five JSON bid-request examples from section 6.2 of the
OpenRTB 2.6 specification (Simple Banner, Expandable Creative, Mobile, Video, PMP with Direct Deal),
copied unmodified apart from whitespace from
<https://github.com/InteractiveAdvertisingBureau/openrtb2.x/blob/main/2.6.md>.
